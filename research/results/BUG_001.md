# BUG-001: irrelevant objective counters affected repetition
Severity: medium/high rules correctness. Found by inspection during first screening. In the original engine, every candidate incremented central-royal hold counters. Only Nexus actually uses those counters as an objective. Including irrelevant unbounded counters in other variants' repetition key could delay a threefold draw.

Correction: update hold counters only when Config.goal == 'hold'; all other candidates retain zero counters. Retest: dedicated regression asserts a central royal move in Ember keeps (0,0); suite expanded to 12 tests. Full screening rerun is candidates_v2.json; the original unfinished screening was interrupted and discarded. Ladder rerun overwrites original pre-fix ladder; initial reported counts were preliminary. This fixes identified state semantics, not every possible draw bug.
